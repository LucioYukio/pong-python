# Pong em Python

Projeto de um jogo Pong desenvolvido em Python utilizando a biblioteca PPlay.

## Funcionalidades

- Movimento da bola com física básica
- Colisão com paredes e paddles
- Sistema de pontuação
- Controle do jogador via teclado
- Inteligência artificial simples para o oponente

## Adicional

Após 3 rebatidas da bola, os paddles são divididos em dois menores com um espaço entre eles, aumentando a dificuldade do jogo e introduzindo uma nova dinâmica de gameplay.

## Conceitos aplicados

- Lógica de programação
- Programação orientada a objetos (POO)
- Estrutura de game loop
- Manipulação de eventos e estados
- Controle de colisão

## Controles

- **Seta para cima** → mover paddle para cima  
- **Seta para baixo** → mover paddle para baixo  
- **Espaço** → iniciar/reiniciar o jogo  

## Tecnologias utilizadas

- Python
- PPlay
